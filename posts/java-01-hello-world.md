# 출력 함수

> - **System.out.println()**

- 기능: 괄호 안의 매개변수에 대한 출력
- 문자의 경우 따옴표로 감싸줘야 함
- 숫자나 논리형 변수에 대해서는 따옴표 필요 X

---

# Code

```java
package chap_01;

public class _01_HelloWorld {
    public static void main(String[] args) {
        System.out.println("Hello World!");    // 문자열 출력
    }
}
```
