# 만든 이유

다운로드 폴더에 파일이 계속 쌓여서, 종류별로 한 번에 정리해 주는 도구를 만들었습니다. LLM을 코드 작성에 써 보는 연습을 겸한 첫 맥 프로그램입니다. 2026년 7월 16일에 처음 만들었고, 첫 실행에서 264개 파일이 정리됐습니다.

---

# 무엇을 하나

메뉴바에 상주하는 macOS 앱이고, 같은 규칙을 쓰는 Python CLI도 있습니다.

- 다운로드 폴더 최상위의 파일을 문서·이미지·영상음악·설치파일·압축파일·코드개발·기타 7개 폴더로 옮깁니다.
- 옮기기 전에 어떤 파일이 어디로 가는지 미리 볼 수 있습니다.
- 마지막 정리를 통째로 되돌릴 수 있습니다.
- 1시간마다 자동으로 정리하는 옵션과 로그인 시 자동 시작 옵션이 있습니다.

---

# 설계에서 신경 쓴 것

파일을 옮기는 도구라서 파일을 잃어버리지 않는 것을 가장 먼저 생각했습니다.

- 폴더는 건드리지 않고 최상위의 파일만 옮깁니다.
- 다운로드 중인 파일(`.crdownload`, `.part` 등)과 수정한 지 10분이 안 된 파일은 건너뜁니다.
- 이름이 겹치면 덮어쓰지 않고 `보고서 (1).pdf`처럼 저장합니다.
- 모든 이동을 기록 파일에 남깁니다. 도중에 오류가 나도 그때까지 옮긴 파일은 기록돼서 되돌릴 수 있습니다.

---

# 리팩토링에서 배운 것

처음에는 분류 규칙이 Python 코드와 Swift 코드에 따로 적혀 있었습니다. 규칙을 `rules.json` 하나로 합쳐 CLI와 앱이 같이 읽게 했고, Swift 코드도 로직·메뉴·미리보기 창으로 파일을 나눴습니다. 규칙을 한 군데에서만 고치면 되고, 앱과 CLI의 되돌리기 기록도 서로 호환됩니다.
